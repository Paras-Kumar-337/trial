Git Commands:

1. git init
2. git status
3. git add (For all files => git add .)
4. git commit -m "First commit"
5. git merge <branch-name>
6. git branch (add name for new creation)
7. git switch <branch-name>
8. git branch -M main (changing to main)
9. git remote add origin <link-to-github-repo>
10. git push -u origin main
11. git fetch
